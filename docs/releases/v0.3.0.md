# v0.3.0

v0.3 introduces the first native ios application shell for loundrycode.

## included

- vibrant swiftui home experience
- code-driven spinning loundy mascot
- idea input and build entry point
- ai's environment surface
- svg-based visual assets and icons
- xcode project for an unsigned sidestore ipa build
- github actions packaging for an unsigned ipa artifact

the app shell stays separate from the swift package foundation so the core architecture can continue evolving independently.
